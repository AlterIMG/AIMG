# ALTERIMAGE

An interactive avatar and banner creator with a guided customization flow, Face DNA, Solana-inspired backgrounds, and downloadable PNGs.

This is a browser-based static website prototype. It is not affiliated with Solana or the Solana Foundation.

## Deploying to Render

This repository contains `index.html` and `render.yaml`.

- Build command: `mkdir -p public && cp index.html public/index.html`
- Publish directory: `public`

The site uses browser storage for saved looks. AI image generation, wallet features, and account backends are not included in this build.
